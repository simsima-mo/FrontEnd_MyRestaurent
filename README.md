# 🍽️ Table Designer 3D – Expérience unique de personnalisation de table

Bienvenue dans le projet **Table Designer 3D**, une plateforme innovante permettant aux clients d’un restaurant de **concevoir et personnaliser leur propre table** en 3D avant leur arrivée ! ✨

---

## 🎯 Concept du projet

Ce projet vise à offrir une **expérience immersive et personnalisée** aux clients des restaurants, en leur permettant de :

- Visualiser une table réaliste en 3D
- Choisir des éléments comme : chaises, verres, assiettes, cuillères, nappes…
- Glisser-déposer facilement ces objets sur la table
- Organiser et prévisualiser l’aménagement de leur table avant réservation

---

## 🛠️ Technologies utilisées

- **React.js** – Interface utilisateur
- **Three.js** – Moteur 3D pour l’affichage et les interactions
- **GLTF/GLB** – Modèles 3D réalistes
- **OrbitControls** – Navigation et rotation de la scène

---

## 🚀 Fonctionnalités

✅ Affichage réaliste d'une table en 3D  
✅ Boutons pour changer les catégories (chaises, verres, assiettes...)  
✅ Système de glisser-déposer d’objets  
✅ Chargement dynamique des modèles `.glb`  
✅ Contrôle total de la vue (rotation, zoom...)  
✅ Interface utilisateur intuitive et responsive
